MECOB ARCHITECTURE

The Sovereign Networking Stack

Deterministic, zero-garbage-collection infrastructure built in Rust.
Wire-speed packet filtering, cryptographic ingress, and recursion.

CARAKA Edge Courier
Multi-protocol client & proxy. Relays plaintext edge queries into encrypted QUIC/TLS datagrams directly to boundary gateways.
DoQ / DoH / DoT Zero-Copy Client
KALAS Kernel Sentinel
eBPF / XDP autonomous perimeter shield. Drops flood vectors and malformed traffic directly inside the network driver before userspace context switches.
XDP Driver Fastpath < 50ns Drop Latency
GAPURA Ingress Gateway
High-throughput ingress reverse proxy. Terminates DoQ, DoH, and DoT sessions, manages session tickets, and routes clean payloads to resolver cores.
Quinn + Rustls Connection Pooling
RUNUT Recursive Core
High-performance recursive resolver and cache engine. Bypasses standard kernel sockets with AF_XDP, delivering sub-millisecond recursive queries.
AF_XDP Native Core Zero-GC Memory Pool
